## Rules of engagement
1. **Ownership.** You edit only the files in your assignment (new files in your areas are fine). Four other agents work at the same time on disjoint areas. If something outside your files must change, do not edit it: put it in your report under "Needs lead". New strings: a local `export const copy = { mn, en }` next to the component (or in the i18n area file you own). Never edit `src/i18n/mn.ts|en.ts` unless the assignment says so.
2. **Server and data.** The dev server is already running at http://localhost:3100 (HMR). Never start/stop/restart it, never run `next build`, never call `/api/dev/reset` or `resetDemoData` (the lead resets between waves). The mock database is shared and mutable by all agents: tests must create their own records with a unique prefix and not assert global counts. If a page 500s with a ChunkLoadError or HMR error that is not yours, wait 20 s and retry.
3. **Method.** TDD: write the failing test first, run it, implement, run again. Unit tests in `tests/unit`, e2e in `tests/e2e` (serial; `workers: 1`). Run e2e sparingly and only your own specs plus `tests/e2e/nav-crawl.spec.ts` (shared CPU): when your task fixes an audit finding, remove its `test.fixme` and its `KNOWN` entry in `nav-crawl.spec.ts` (only those lines).
4. **Quality.** `docs/design/polish-rubric.md` and plan Global Constraints apply: tokens only, light + dark, 390/768/1280, tap targets (/me ≥ 44 px, admin ≥ 40 px), no horizontal scroll, labels on every field, errors beside the field, logging per org standard (constant `message`, snake_case fields, never log emails/codes/tokens). Look at screenshots of what you build (throwaway Playwright script into the scratchpad dir, delete after) at 390 and 1280, light and dark.
5. **Gates before reporting:** `npx vitest run` (whole suite), `npx tsc --noEmit`, `npx eslint .` (zero warnings in your files), your e2e specs, `nav-crawl`. Do **not** commit; the lead commits.
6. **Report** (≤ 15 lines, no code dumps): what you built, files, gate results, findings fixed (ids), anything left, "Needs lead".
